# OutRun Delivery: Infinite Night

**A mobile-friendly synthwave driving and idle delivery game for the browser.** Collect packages on an endless neon highway, dodge traffic, upgrade your courier, build an automated fleet, and earn while you’re away.

## Game features

- **Arcade highway driving:** Switch lanes, collect deliveries, avoid traffic, and engage Overdrive.

- **Idle courier business:** Upgrade your car, grow a fleet, automate operations, and earn offline income.

- **Progression:** Unlock timelines and routes, complete roadside events, and use Dawnbreak prestige resets for permanent bonuses.

- **Mobile controls:** Swipe, tap the left/right sides of the screen, or enable on-screen lane buttons.

- **Responsive interface:** Designed for phone, tablet, and desktop screens.

- **Visual customization:** Four color palettes, a live Garage vehicle display, visible car upgrade parts, varied traffic and scenery, weather, and event transitions.

- **Accessibility options:** Reduced motion and flashes, high-contrast HUD, adjustable text size, and keyboard-accessible menus.

- **Local saves:** Progress stays in the player’s browser. Export/import is available for moving or backing up a save.

## Controls

| Input | Action |
| --- | --- |
| `A` / `D` or `←` / `→` | Change lanes |
| `Space` | Activate Overdrive when charged |
| `1`–`5` | Switch game tabs |
| `Esc` | Close the current dialog |
| Touch | Swipe, tap either side of the road, or use the on-screen arrows |
